# data

נתוני המאפייה, מהפרויקט של המנחה ([bakery-copilot](https://github.com/MaceTenth/bakery-copilot)). נתונים מומצאים, בלי אנשים אמיתיים.

- `bakery_sales.csv`: 29,115 שורות מכירה, ספטמבר 2025 עד אוגוסט 2026, ארבעה סניפים ו-19 מוצרים. נטען ל-Postgres בהפעלה הראשונה, ונקרא רק דרך הכלי `sales_query`.
- `suppliers.csv`: 10 ספקים, עם פריט, יחידה, מחיר ומטבע (EUR, USD, GBP). נטען לטבלת `suppliers`, ומשמש את הכלי `lookup_supplier`.
