# Lavender Bakery Copilot

## להגשה (שיעור 10)

- **האתר ב-Railway:** https://web-production-09c5f.up.railway.app (סיסמת הצוות נשלחה בנפרד)
- **מבוסס על:** [bakery-copilot](https://github.com/MaceTenth/bakery-copilot) של המנחה. מסמכי המקור שלו שמורים ב-`reference/bakery/`.

**מה שיניתי:**
- **שם ועיצוב:** Lavender Bakery Copilot, לבנדר וסגול, פונט Rubik, 🌼, מותאם לטלפון.
- **עברית:** כל הממשק בעברית ומימין לשמאל. הבוט עונה בעברית חמה, עם תאריכים בפורמט ישראלי.
- **הבוט:** "היום" נקבע ליום האחרון בנתונים (אוגוסט 2026), כדי ש"שבוע שעבר" יחזיר תשובה. רשימת המוצרים נמצאת בפרומפט, אז הוא מחפש ישר `Challah`: פעולה אחת במקום שתיים, בערך 23% זול יותר.
- **ממשק:** פרטי הכלים והעלות מוסתרים מאחורי חץ "איך הגעתי לתשובה".
- **הגדרות:** אזור אמסטרדם, מודל Sonnet, חיבור ל-9 שעות, סיכום בוקר מראשון עד חמישי (ביום ראשון: חמישי עד שבת). אין webhook, והסיכום נכתב ליומן של Railway.
- **באג שתוקן:** סיסמה שגויה הציגה "צריך להיכנס שוב" במקום "הסיסמה לא נכונה" (issue #2).

**איך עבדתי:** כל שינוי בענף נפרד וב-PR, עם בדיקות CI ירוקות לפני מיזוג (PRs #1, #3–#7). Railway מעדכן את האתר אוטומטית אחרי ה-CI.

**בדיקות:** 42 בדיקות קוד (tests), ו-13 בדיקות התנהגות של הבוט (evals) מול Claude האמיתי, על Sonnet, כמו באתר. שתיהן רצות בכל PR, ו-13/13 עוברות.

> **פרויקט נפרד באותו ריפו:** לפני ההגשה הזו התחלתי לתכנן Copilot אחר, למאגר לקוחות על נתוני Kaggle. התכנון שלו נמצא ב-[`spec.md`](spec.md) וב-[`docs/customer-copilot-plan.md`](docs/customer-copilot-plan.md).
