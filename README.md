# Customer Copilot

> **שלב א (הגשת שיעורי בית):** הקוד מבוסס על [bakery-copilot](https://github.com/MaceTenth/bakery-copilot) של המנחה, ומותאם: שם, עיצוב, עברית ופרומפט. מסמכי המקור שלו שמורים ב-`reference/bakery/`.

צ'אט בעברית שבעל עסק מדבר איתו על מאגר הלקוחות וההזמנות שלו. תרגיל בית בהנדסת סוכנים (שיעור 9), שלבים 1-4: design, place, manage, test/eval. שלב ה-deploy (Railway) יתווסף אחרי השיעור הבא.

## החלטות שהתקבלו

- ה-Copilot עונה בעברית. המסמכים בעברית, שמות הקבצים באנגלית.
- מסד נתונים: SQLite (קובץ מקומי). מעבר ל-Postgres ייבחן בשלב ה-deploy.
- שפת תכנות: Python כברירת מחדל, **ההחלטה הסופית (Python או Node.js) נשארת פתוחה** עד אחרי השיעור הבא.
- ה-Copilot קורא וגם משנה נתונים, עם שלושה כללים: אישור לפני כל שינוי, מחיקה אסורה, ויומן לכל שינוי.
- שלוש משימות: (1) מענה על שאלות על הנתונים, (2) עדכון לקוח (הערה או סימון "לחזור אליו"), (3) סיכום הזמנות שדורשות מעקב: הזמנות עם דירוג נמוך או בלי דירוג. המשימה הותאמה כי לכל לקוח במאגר יש הזמנה אחת בלבד.
- נתונים: Kaggle, Online Retail & E-Commerce Dataset (מומצא, CC0). ראו `data/README.md`.
